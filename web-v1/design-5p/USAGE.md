# Century 五人版高保真 UI 原型

## 文件

- `index.html`：**直接双击打开**的单文件 UI 演示；默认 2 真人 + 3 AI，顶部可调整 0～3 AI。
- `century-3440x1440-5p.png`：3440 × 1440 默认场景。
- `世纪桌面-预览图-五人.png`：便于查看的缩略截图。
- `双方案布局对照.png`：A/B 方案布局比较，采用双翼固定 A。
- `century-*-state.png`、`century-dense-mode-5p.png`、`century-after-30-actions-5p.png`：主要交互状态截图。
- `设计规范与审计-五人版.md`：完整审计、尺寸、规范及验证边界。
- `reference/cards-canonical.json`：从根目录核校数据重建的**语义一致快照**，不是与远程 JSON 逐字节相同的文件。
- `repo-migration/`：用于未来在本地 V1 工作树统一卡牌数据的 TypeScript 生成器与补丁。没有修改 GitHub 远程仓库。
- `qa-results.json`、`qa.py`：浏览器自动化断言与测试源文件。

## 适用范围

目前是交互式设计原型，能展示和操作两名真人的资源、市场与手牌；AI 卡是信息示例而不是会真实自动行动的对手，原型不等同于五人规则引擎。默认截图来自模拟中后期状态，不能将它视作从真实开局逐回合回放的牌局。

## 数据校核

2026-10-19 GitHub `main/data/cards.json`：2 种起始卡各 5 份 + 43 张商人 + 36 张魔像；数据指纹（按固定字段归一化后）为 `2fd96cfc`，本地快照一致。M29 为黄4→蓝2，M43 为升级3。建议正式游戏 V1 的 `src/data.ts` 使用根目录生成工具，不再维护独立的旧卡号表。

## 浏览器测试

27/27 通过；验证视口 3440×1440、3000×1200、2600×1200、2000×1080 没有整页溢出。30 次模拟真人 UI 操作正常；并非完整五人规则对局测试。
