# 晶石回廊 V1.5 · Focus 极限空间模式

本项目为《Century: Golem Edition》规则的非官方私人学习原型，使用原创文字及几何卡面，不含官方插画、商标或游戏官方授权素材。

## 使用

直接双击 `dist/standalone.html`。Chrome / Edge / Safari 可离线运行。推荐 3440×1440 (UWQHD / 21:9)，默认 2 名真人 + 1 名 AI，可选 0–4 名 AI。2 真人 + 4 AI 是单独注明的非官方六人扩展局。

## V1.5 设计决策

**始终展示：** 双真人左右固定面板、商队水晶及容量、可打出的商人卡、正面已打出商人卡（回收区可折叠）、个人分数及硬币、魔像分数与支付要求、商人市场真实卡面和左侧支付成本、当前回合。AI 在公共桌面下部横向轨道中公开展示正面手牌、水晶、分数与已打出张数。

**删除常驻展示：** 品牌英文副标题、魔像装饰性徽章、重复交易说明、游戏操作指导句、冗余卡牌“打出/等待”脚注、魔像牌库剩余计数、商人牌库剩余计数、每次回合的重复提示、常驻日志面板、AI 独立大卡框和 AI 已打出卡的默认完整展开。

**按需查看：** 标题栏按钮分别提供 AI 暂停/继续、手牌大小切换、行动记录、规则、新局；点击各 AI 轨道左侧可展开其完整手牌及已打出卡牌。鼠标悬停手牌才出现 ‹ › 精调，仍支持拖动和一键按创造/升级/交易分类，调整顺序不消耗回合。

**自适应密度：** 真人手牌根据数量在 4 档尺寸间切换。AI 轨道 1–4 人按照人数计算高度，避免少人局的卡牌被无限拉长；市场始终各自占固定、可预测的高度。3440×1440 双人 + 4 AI 版：两侧真人各约 957px 宽、手牌滚动区约 1154px 高，整页无滚动。

## 开发与验证

### 导出对局复盘

桌面端打开标题栏「行动记录」（☷）。对局进行中和结算后均可导出：

- **Markdown**：可直接阅读的中文复盘，按轮次、全局手数、玩家个人回合排列，包含卡号、获取支付顺序、升级路径、重复交易次数、超额弃置、行动前后水晶/卡牌/硬币/估分以及当前排名。
- **JSON**：`format: century-replay`、`version: 1`，包含 `replay.initial` 起点、`replay.turns` 全部回合和 `current` 导出时局面。依次将每条回合的 `actions` 交给正式 `applyAction`，即可从起点重放。此文件用于分析。

新局从开局完整记录，覆盖全部真人和 AI，不受近期日志 45 条限制；记录随本地存档保存。超额弃置合并到对应回合，尚未弃置的回合标记为未完成。旧版 v2 存档可继续使用，首次新行动从接续局面开始记录，导出会注明历史缺失，无法恢复旧版已经丢弃的行动。新局会覆盖本局，复盘需要先导出保存。

复盘回归：`node --test tests/replay.test.mjs`（先构建）；`python scripts/smoke_replay.py` 验证 Chromium/WebKit 的复盘下载及刷新续局。设置 `CENTURY_TEST_URL` 可对部署地址进行同样检查。

```bash
npm install
npm test
python3 scripts/smoke_focus.py
python3 scripts/smoke_organize.py
```

`src/data.ts` 从根目录 `data/cards.json` 生成，89 张实体卡保持规范卡号和效果。每位玩家持有 S01 / S02 各一份；六人扩展复用相同起始卡效果，不增加实体牌库。
存档使用版本 2 和 `crystal-corridor-game-v2-canonical`，隔离旧卡号存档。

## AI V2.0

- **多回合束搜索**：每个公开魔像单独规划（最多 6 次自身行动，典型宽度 18），比较路径得分与时间成本；未来对手行为暂不模拟。
- **完整行动类型**：重复交易、逐级升级、创造、休息、获取和认领均纳入候选；获取最多搜索一次，避免爆炸式分支。
- **资源与硬币**：回合结束按 10 颗容量优化弃置，识别前两张魔像的铜币与银币，计算认领实际支付。
- **公开信息边界**：只使用自己的水晶/商人卡、可见市场与公开得分；搜索**不读取**两类隐藏牌库的顺序，假设市场未知补牌暂不出现。
- **终局**：已经触发终局时只搜索一次自身行动；其他临近终局局面缩短搜索深度。
- **保证合法**：规划后的第一动作重新经正式 `applyAction` 校验，必要时回退到合法动作。
- **测试**：`npm test`，涵盖真实 M20→M23→G14 三步路径、休息成本、未知牌序隔离和终局，以及原有规则/整局合法性。
- **对战衡量**：`npm run build && node scripts/benchmark-ai.mjs 8`；按相同随机种子轮换 V1/V2 座次，统计胜场、胜率、分差。胜率须以实测输出为准，勿预设 V2 必胜。
- **离线入口**：`dist/standalone.html` 已包含 V2.0 策略代码。此版本升级 AI，不代表游戏规则和整体 UI 已升级到 V2。

局限：束搜索有启发式截断，不保证全局最短路线；不会预测对手未来动作、被抢走的目标或未知翻牌，这些保留给后续 V2.1。当前同步运行在主线程，待真实机器性能测试后决定是否移至 Web Worker。
