# Century 手机版视觉设计规范 · 「墨玉与象牙」

> 视觉方向 B：Premium Physical Boardgame × Apple 排印纪律。
> 本规范描述 `design-mobile/index.html` 演示页的实现参数，可逐条迁移到正式版 `web-v1/src/mobile/styles.css`。

---

## 1. 设计原则

1. **卡牌是主角**：深色桌面只做氛围，象牙纸卡承载全部信息。
2. **水晶是唯一高饱和元素**：四色水晶之外，界面全部低饱和（墨玉/象牙/青铜/玉绿）。
3. **形状辅助辨色**：四色水晶各有独立轮廓，色弱用户可纯靠形状区分。
4. **无冗余文字**：微型卡面零文字（类型/编号/费用说明全部移除），规则细节进入浮层。
5. **克制的动效**：仅浮层升入（260ms）、按压反馈（120ms）两处。

## 2. 色彩系统

### 2.1 墨玉桌面（背景）

| `--ink-700` | `#2B251D` | 商队皮面高光 |

### 2.2 象牙纸卡

| Token | 值 | 用途 |
|---|---|---|
| `--paper-hi` | `#FBF6EA` | 卡面渐变顶 |
| `--paper` | `#F3ECDB` | 卡面渐变中 |
| `--paper-lo` | `#E4D8BE` | 卡面渐变底 |
| `--paper-line` | `#B9A67D` | 卡牌外框 |
| `--paper-ink` | `#3B3122` | 卡面主文字 |
| `--paper-ink-soft` | `#7A6C52` | 卡面次文字 |

卡面构成（自上而下叠加）：
1. 类型顶釉：`radial-gradient(90% 42% at 50% 0%, …, transparent 70%)` —— 创造 `rgba(216,164,52,.14)` / 升级 `rgba(96,142,96,.16)` / 交易 `rgba(74,146,198,.13)`
2. 纸张渐变 `linear-gradient(168deg, hi, paper 52%, lo)`
3. 纸纹：两组 1px 重复线（透明度 .02–.028）
4. 内框：`inset 2.5px` 处 1px `rgba(150,128,86,.30)` 圆角细线
5. 顶部内高光 `inset 0 1px 0 rgba(255,255,250,.85)` + 外阴影 `0 1px 1px #00000080, 0 3px 9px #00000052`

### 2.3 四色水晶（唯一饱和焦点）

| 色 | 形状 | hi / mid / deep / rim |
|---|---|---|
| 黄 | 六方柱 hex | `#F7D678` / `#E2AC3F` / `#A67415` / `#7A5410` |
| 绿 | 祖母绿切 octagon | `#8CCB97` / `#4F9E63` / `#2C6B40` / `#1E4C2D` |
| 蓝 | 菱尖 diamond | `#86C4EA` / `#4A92C6` / `#2A5D8D` / `#1B4266` |
| 粉 | 五棱 pentagon | `#EFAAC6` / `#D0789E` / `#9C4A6F` / `#6E3050` |

水晶渲染分层：
- 底部暗面 `linear-gradient(0deg, rgba(0,0,0,.30) 0%, transparent 30%)`
- 顶点高光 `radial-gradient(130% 85% at 30% 12%, rgba(255,255,255,.85), transparent 44%)`
- 主体 `linear-gradient(155deg, hi 4%, mid 55%, deep 100%)`
- 切面棱线 `::after`：`linear-gradient(205deg, rgba(255,255,255,.5), transparent 46%)` + `clip-path: polygon(0 0,100% 0,58% 100%,0 52%)`
- 轮廓：`filter: drop-shadow(0 0 .5px rim) drop-shadow(0 1px 1px rgba(0,0,0,.4))`（跟随 clip-path，小尺寸仍清晰）

## 4. 水晶尺寸档

| 档位 | 宽×高 | 用途 |
|---|---|---|
| `sz-xs` | 9×11 | 卡面水晶、奖励托盘、魔像需求 |
| `sz-s` | 11×13 | 手牌/市场卡面（升级 2px 间隙） |
| `sz-m` | 13×16 | 浮层选择器 |
| `sz-l` | 17×20 | 商队槽、浮层预览 |
| `sz-xl` | 24×29 | 浮层需求大水晶 |

商队槽与 `sz-l` 同尺寸；空槽为同形状暗刻（`rgba(255,244,214,.06→.02)` + 深色 drop-shadow）。

## 5. 布局参数（390×844 基准）

```
stage: 100dvh 网格, rows = auto auto auto minmax(0,1fr) auto, gap 5px, 左右 8px
topbar   40px   eyebrow + 标题 + 44pt 菜单按钮
players  34px   2 列座次芯片（active: 玉绿描边+光点）
caravan  54px   皮面渐变 + 名称/硬币/6÷10 + 10 槽水晶条
markets  1fr    行比 54:46；标题行 20px；魔像卡 ≤170px、商人卡 ≤138px
hand     ~250px 标题行 44pt + 5×2 网格（卡 ≤102px）+ 44pt 休息胶囊
```

断点：
- `≤359px`：内距 6px、间隙 3px、水晶 12×15、隐藏提示文字
- `≤690px` 高：魔像 ≤124 / 商人 ≤100 / 手牌卡 64–92 / 商队槽 13×16
- `≥780px` 高：魔像 ≤170 / 商人 ≤138 / 手牌卡 92–102
- `≥420px` 宽：魔像 ≤176 / 商人 ≤142

## 6. 交互状态

| 状态 | 视觉 |
|---|---|
| 可认领魔像 | 2px 玉绿外框 + `0 0 12px rgba(111,191,138,.28)` 光晕 + 右上角玉绿圆点徽章 |
| 已打出卡 | `grayscale(.58) brightness(.86) opacity(.66)` + 135° 斜纹封存（3px/7px 周期） |
| 按压 | `scale(.965)`，120ms |
| 浮层 | 底部升入 260ms `cubic-bezier(.2,.85,.25,1)`；scrim `rgba(10,8,4,.55)` + `backdrop-filter: blur(7px)` |
| CTA | 玉绿渐变胶囊，44pt 高，字距 5px；禁用转墨色 |
| Toast | 象牙纸药丸，底部 112px，3s 自动消失，打开浮层时隐藏 |

## 7. 命中区

全部可点元素 ≥ 44×44 CSS px：菜单、手牌管理、休息、浮层关闭、步进器、选择器（52pt）。市场/手牌卡宽 48–72px、高 64–176px，天然满足。
