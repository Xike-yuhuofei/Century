# Century 手机版 UI 视觉升级 · 高保真概念演示

**视觉方向 B「墨玉与象牙」** — Premium Physical Boardgame × Apple 排印纪律。
本目录为独立演示，未修改正式 `/mobile/` 页面与任何正式代码。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 可交互演示（自包含单文件，含真实卡牌数据与迷你规则引擎） |
| `DESIGN-SPEC.md` | 视觉设计规范（色彩/字体/水晶/布局/交互状态全参数） |
| `qa_screens.py` | 双引擎 × 四视口自动化 QA 脚本（Playwright） |
| `shots/` | 20 张实机渲染截图（Chromium + WebKit） |

## 运行

```bash
# 方式一：直接双击 index.html（离线可用）
# 方式二：本地服务器
cd web-v1/design-mobile && python3 -m http.server 4199
# 打开 http://localhost:4199/

# 复跑视觉 QA
python3 qa_screens.py
```

## 规则与数据真实性

- 卡牌数据逐字同步自 `data/cards.json`（S01/S02、M01–M43 子集、G02–G36 子集）。
- 迷你引擎与 `web-v1/src/engine.ts` 规则一致：打出（创造/逐级升级/重复交易）、按位获取与奖励累积、按位认领与硬币、休息收回、>10 颗强制弃置。
- 演示沙盒不推进回合（便于连续探索），浮层内已注明。

### 未实测 / 已知边界

- 未在真实 iPhone Safari（Touch ID 代际）与 Android Chrome 真机上验证；WebKit 结论基于 Playwright WebKit 18.4。
- 横屏模式未纳入本演示范围（任务书视口均为竖屏）。
- `backdrop-filter` 在极旧 WebKit（<iOS 9）不可用，届时 scrim 退化为半透明纯色，可接受。
- 动态视口高度使用 `100dvh` + `100vh` 双声明；iOS Safari 界于两者之间的行为以真机验证为准。

## 与正式版的关系

- 演示位于独立目录，未触碰 `web-v1/src/mobile/*`、`web-v1/mobile/*` 与 `main` 分支构建产物。
- 迁移路径：按 `DESIGN-SPEC.md` 参数替换 `styles.css` 的 token 与组件层；`app.ts` 的卡面渲染函数可对照 `index.html` 内 `cardHTML/gemsHTML/golemHTML` 重写（约 120 行）。
