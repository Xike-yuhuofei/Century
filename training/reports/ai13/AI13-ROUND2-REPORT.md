## 1. 动机

AI13 第一轮定位到：冠军强度主体是联合仲裁，而仲裁未来的自身策略是 1-ply 贪心，
与冠军计划首步一致率仅 56.5%。第一轮的廉价蒸馏（同分布 63.2%、JS5 标签 49.4%）
未能补上该缺口。第二轮改为**不依赖学习模型的结构性融合**，检验三个可证伪假设：

| 假设 | 机制 | 预期 |
|---|---|---|
| H-A2 终局动机 | 冠军规划器对“完成最后一次认领/触发终局”的路线没有显式加分 | 5p 因缺少终局动机而少认领；加分会提升 5p |
| H-C3 计划跟随 | 轨迹内自身策略跟随冠军计划路径（合法时），而非 1-ply | 提高模拟保真度，改善仲裁 |
| H-C4 目标锁定 | 轨迹内自身策略锁定冠军计划目标，动作仍由 1-ply 选 | 减少目标抖动，改善长期一致性 |

全部选项：`championTerminalBonus` / `championTerminalAware`、`selfPlanFollowing`、
`selfGoalLock`；缺省 0/false，生产路径逐位不变。

## 2. 实验结果

### 2.1 H-A2 终局路线加分：惰性

源码事实：`planner.routeGrade` 只在 `state.terminal` 时消费 `endgameBonus`，
而冠军的 `endgameBonus` 模块缺省返回 0；对“路线完成最后一次认领”没有额外加分。

决策探针（5p，262 个焦点决策）：

| 选项 | 改变决策 | 结论 |
|---|---|---|
| `championTerminalBonus=12, aware=true` | **0 / 262（0.00%）** | 惰性 |
| `championTerminalBonus=20, aware=false` | **0 / 262（0.00%）** | 惰性 |

结论：该选项在 5p 开发探针中不改变任何行动，未进入配对筛选。
未验证推测：depth 6 的束内很少出现“最后认领”路线，或路线切换不改变首步；
需要更长视野/不同规划目标才可能触发，不能据此声称“终局动机不重要”。

### 2.2 H-C3 计划路径跟随：方向不利，未筛选

5p 决策探针（262 个决策）：

- 初版（允许计划中的 rest）：改变 **41 / 262（15.65%）**，大量 `play/acquire → rest`；
- 改为“计划中的 rest 交给 1-ply”后：改变 **35 / 262（13.36%）**，仍以 `play/acquire → rest` 为主。

源码事实：计划路径是在根状态、按“无对手行动/无未知补牌”展开的；进入 rollout 后对手已行动、
市场已变化，路径动作经常不合法或已陈旧。继续强制跟随会把“回牌/停滞”注入模拟未来。
**判定：机制方向不利于转换，未进入配对筛选**（这是机制判断，不是胜负率统计结论）。

### 2.3 H-C4 目标锁定：改变行动，但 5p 增量不足且非劣效失败

目标锁定只改轨迹内自身策略的目标偏好，动作仍由 1-ply 选择；计划目标被对手认领后自动回退。

**非惰性证据**（决策探针，开发池）：

| 人数 | 决策数 | 改变 | 改变率 |
|---|---|---|---|
| 5p | 262 | 40 | 15.27% |
| 2p | 161 | 13 | 8.07% |
| 3p | 163 | 31 | 19.02% |
| 4p | 141 | 27 | 19.15% |

**5p 配对屏幕**（同种子、同座位、同对手；WU=64；N=192）：

| 指标 | 值 |
|---|---|
| 5p 第一名率增量 | **+2.60pp** |
| 95% 区间（t 近似） | **[−4.93, +10.14]pp** |
| sd(delta) | 63.4pp |
| 平均分 A / B | 60.7 / 60.3 |
| 魔像数 A / B | 3.93 / 3.98 |
| 异常对局 | 0 |
| 墙钟 | 39.3 min |

**统计结论**：

1. 点估计 +2.60pp 不显著（区间跨 0）；
2. 单侧下界 −4.93pp **低于 −2pp 非劣效门槛**——即使只看开发池口径，5p 也不能通过非劣效；
   在正式 α（固定期限家族 α=1/240，z≈2.64）下下界会更低；
3. 若 2–4p 行为收益为 0，综合增量仅 +0.65pp，低于 +2pp 正式门槛，更低于研究优先的 +5pp；
4. 因此不再为 2–4p 追加 192 种子级筛选（5p 非劣效已失败，组合也无法晋级）。

**判定：目标锁定不是合格候选。**

## 3. 与第一轮/历史证据的关系

- 第一轮 L6 探索 +14.58pp → 复现 −7.29pp；horizon 96 综合 −3.13pp；蒸馏 63.2%/49.4%。
- 本轮三种结构融合：终局加分为惰性，计划跟随方向不利，目标锁定 +2.60pp 不显著且非劣效失败。
- 合并后的结论不变：**在现有束搜索 + 联合仲裁架构内，未找到可复现的综合正向增量**。
  冠军保持 `joint-js5`；正式挑战 0 次；alpha 0/12。

## 5. 下一轮可证伪假设（按证据强度）

1. **H4（2-ply 自身策略）**：在 rollout 内对前 2 个动作做 depth-2 评估，同 100ms 墙钟下
   比较“保真度收益 vs 试验数下降”；若净负则彻底放弃廉价保真度路线。
2. **H3（仿真校准）**：先测 rollout 内对手认领率与真实对手认领率差距，再拟合受约束偏置；
   本轮 `opponentClaimBias=0.2` 仅改 0.8% 决策，说明常数偏置不是有效校准。
3. **H6（终局名次概率投影）**：用剩余动作数、认领槽、可达费用投影最终名次概率，
   替换 L2 的加性 margin；需 N≥192 + 独立复现。
4. **H7（架构级）**：若上述均失败，考虑把仲裁从“根动作 rollout 均值”改为
   “计划目标条件化的分层搜索”，但必须保持 100ms 生产预算与同预算比较。

在 H1（5p N≥192 + 独立复现）满足前，任何 5p 单窗口 +8~15pp 读数都只能视为噪声。
